# Smoke Checklist

Run after each deployment.

- API health endpoint responds.
- Web app loads.
- Registration page loads.
- Login works for seeded test user.
- Authenticated dashboard loads.
- Course catalog loads.
- A lesson can be opened.
- A quiz can be submitted.
- Progress dashboard loads.
- Notification list loads.
- Admin login works.
- Admin dashboard loads.
- Swagger/OpenAPI is reachable in allowed environments.
- No critical browser console errors on primary pages.
- No critical backend errors in logs.
