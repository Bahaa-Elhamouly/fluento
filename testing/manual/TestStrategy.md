# Manual QA Strategy

Manual QA supplements automated tests with exploratory, usability, content, and release validation.

## Focus Areas

- New learner onboarding.
- Lesson clarity.
- Quiz feedback usefulness.
- Admin content workflows.
- Responsive behavior.
- Accessibility basics.
- Error message clarity.
- Edge cases not yet automated.

## Rules

- Critical paths should eventually be automated.
- Manual bugs must include reproduction steps and evidence.
- Regression testing should focus on changed and adjacent areas.
- Smoke testing is mandatory after deployment.
