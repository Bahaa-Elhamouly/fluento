# Fluento Test Plan

## Objective

Validate that Fluento delivers secure authentication, reliable learning workflows, accurate progress tracking, admin management, and stable production behavior.

## Scope

MVP test scope includes:

- Authentication.
- User profile and preferences.
- Courses, modules, and lessons.
- Vocabulary.
- Grammar.
- Quizzes.
- Progress.
- Notifications.
- Admin CRUD.
- API response contracts.
- Security basics.
- Deployment smoke testing.

## Test Types

- Unit testing.
- Integration testing.
- API testing.
- Playwright E2E testing.
- Manual functional testing.
- Regression testing.
- Smoke testing.
- Security checklist testing.
- Performance baseline testing.

## Entry Criteria

- Feature requirements documented.
- API/database changes merged in a testable environment.
- Test data available.
- Known blockers triaged.

## Exit Criteria

- Critical and high defects resolved.
- Required tests pass.
- Smoke checklist passes.
- Regression checklist completed for impacted areas.
- Test summary and closure report completed.

## Test Environments

- Local development.
- CI test environment.
- Staging.
- Production smoke environment.
