# API Test Collection Plan

## Tooling

The API collection can be implemented using Postman, Bruno, REST Client, or automated test code. The selected tool must be runnable in CI when possible.

## Collections

- Auth.
- Users.
- Courses.
- Lessons.
- Vocabulary.
- Grammar.
- Quizzes.
- Progress.
- Notifications.
- Admin.

## Required Assertions

- Status code.
- Response envelope.
- Error code.
- Validation errors.
- Authentication requirements.
- Authorization requirements.
- Database side effects where applicable.
