# Analytics

## Product Analytics

Track learner behavior and outcomes:

- Registration conversion.
- Login frequency.
- Daily active learners.
- Lesson starts and completions.
- Quiz attempts and scores.
- Vocabulary reviews.
- Streak retention.
- Achievement unlocks.
- Subscription conversion.

## Admin Analytics

Admins need visibility into:

- Active users.
- Course engagement.
- Lesson completion rates.
- Quiz difficulty.
- Content performance.
- Subscription and payment status.
- Notification delivery.
- AI usage and failures.

## Data Rules

- Analytics must respect privacy and security requirements.
- Do not store sensitive AI prompts in analytics events.
- Use stable event names.
- Include versioned metadata when event shape changes.
