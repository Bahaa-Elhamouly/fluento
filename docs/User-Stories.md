# User Stories

## Student Authentication

- As a student, I want to register so I can create my Fluento account.
- As a student, I want to log in securely so I can access my learning data.
- As a student, I want to verify my email so my account is trusted.
- As a student, I want to reset my password so I can recover access.

## Student Learning

- As a student, I want to choose a target language so my learning content is relevant.
- As a student, I want to select my learning level so lessons match my ability.
- As a student, I want to follow course modules so I know what to study next.
- As a student, I want to complete lessons with exercises so I can practice actively.
- As a student, I want to save vocabulary favorites so I can review difficult words.
- As a student, I want grammar examples so I can understand usage in context.
- As a student, I want instant quiz feedback so I can learn from mistakes.

## Student Progress

- As a student, I want XP and streaks so I can track consistency.
- As a student, I want achievements so I feel rewarded for milestones.
- As a student, I want weekly progress so I can understand my learning habits.
- As a student, I want daily goals so I stay consistent.

## AI Practice

- As a student, I want an AI conversation partner so I can practice realistic dialogue.
- As a student, I want AI writing feedback so I can improve sentence construction.
- As a student, I want AI speaking feedback so I can improve pronunciation.

## Admin

- As an admin, I want to manage users so I can support learners.
- As an admin, I want to manage courses, modules, lessons, vocabulary, grammar, and quizzes so content stays current.
- As an admin, I want analytics so I can monitor usage and learning outcomes.
- As an admin, I want AI configuration controls so AI behavior remains aligned with product and safety standards.
